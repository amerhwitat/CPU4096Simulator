# CPU4096Simulator Kotlin Mobile

Native Android Kotlin implementation for the simulator dashboard. It is isolated from the existing Node.js/JavaScript runtime and provides a mobile entry point for ISA, memory/MMIO, robotics, networking, and 128D research state visualization.

The module uses Kotlin 2.4.20, AGP 9.4.0, SDK 36, and JDK 17. Network access is intentionally absent from the starter UI; any future trusted-node transport must follow the portfolio authenticated P2P contract.

# Crypto AI simulation workloads

CPU4096Simulator can consume deterministic crypto and neural benchmark vectors from the Python research layer.

Targets include SHA/Keccak, modular arithmetic, CNN convolution, GRU/RNN recurrence and offline RL environment stepping. Benchmark traces should identify ISA width, vector shape, dataset hash, seed and model version.

The simulator does not implement private-key recovery or address-targeted brute force.

# Chimera II Desktop Synchronization

The CPU4096Simulator participates in the Chimera II research stack. The canonical Web desktop and unified help implementation is maintained in `amerhwitat/ChimeraIIOS`.

The Aurora Wayland Glass desktop uses Three.js/WebGL with an accessible HTML layer. Desktop profiles cover Linux families and Windows UI profiles. Native host sessions, VM and RDP integration must remain explicitly authorized and sandboxed.

Canonical source: https://github.com/amerhwitat/ChimeraIIOS

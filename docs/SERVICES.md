# Chimera II Web Service Catalog

The catalog includes the previously defined cross-platform stack without bundling third-party binaries into the browser application.

- Shells: bash, zsh, fish, PowerShell (`pwsh`)
- Utilities: coreutils/uutils, awk/gawk, sed, grep, findutils, util-linux, procps, iproute2, iputils, jq/yq, diff/patch, tar/cpio, gzip/bzip2/xz/zstd, make/binutils/GCC/GDB
- Runtimes: Python, Java, .NET, Node.js, Perl, Ruby, PHP
- Networking: OpenSSH, curl, wget, rsync, IPv4/IPv6, DNS, SMB/NFS, WireGuard/OpenVPN
- Services: sshd, Samba, NFS, BIND/dnsmasq, Apache/nginx/Caddy, Postfix/Dovecot, chrony, rsyslog, cron/systemd/D-Bus, Avahi/CUPS/BlueZ, libvirt, Podman/Docker/containerd/k3s, PostgreSQL/MariaDB/Redis, Mosquitto
- Filesystems: FAT/exFAT/NTFS/ReFS/ext4/XFS/Btrfs/ZFS/NFS4/SMB3/UFS/APFS/HFS+/tmpfs/overlayfs

These entries are capability metadata and integration targets. They are not claims that the web browser can directly install or execute host daemons.

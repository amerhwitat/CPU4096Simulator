# Chimera 128D + P2P Portfolio Integration

CPU4096Simulator uses the common Chimera semantic state and authenticated peer envelope.

The 128D profile describes CPU/register/workload topology, temporal state, observer/perspective, events, objects and extensible cognition/vector state. P2P is opt-in and supports health, capability, workload, snapshot and delta exchange with payload hashes, sequence validation and local authorization.

Browser transport can use WebSocket/WebRTC while preserving the same logical JSON contract.

The protocol does not perform unsolicited scanning, distribute credentials/private keys, transfer arbitrary executables or provide remote command execution.

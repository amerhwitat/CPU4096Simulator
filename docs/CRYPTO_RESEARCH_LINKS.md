# Crypto Research Links

The simulator can model synthetic cryptographic workloads relevant to Chimera II wide-register and C8192/R8192 research.

- BIP-32: https://github.com/bitcoin/bips/blob/master/bip-0032.mediawiki
- ERC-55 / EIP-55: https://eips.ethereum.org/EIPS/eip-55
- ERC-1191: https://eips.ethereum.org/EIPS/eip-1191
- Bitcoin Core secp256k1: https://github.com/bitcoin-core/secp256k1
- bitcoinjs/bip32: https://github.com/bitcoinjs/bip32
- scure-bip32: https://github.com/paulmillr/scure-bip32
- Chimera II provenance catalogue: https://github.com/amerhwitat/ChimeraIIOS/blob/main/docs/CRYPTO_UPSTREAMS_AND_PROVENANCE.md

Only synthetic/test vectors and legitimately possessed key material should be used. No public-address-to-private-key search or wallet targeting is part of the simulator scope.
